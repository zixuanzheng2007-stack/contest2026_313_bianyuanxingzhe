# DevKit-LCD · LD2451 排针接线（无丝印时按针号数）

来源：思澈 `SF32LB52-DevKit-LCD_V1.2.0` 设计包  
连接器：`J0117` = **CON-2X20P（树莓派 40P 兼容排针）**  
软件定案：UART2 = PA27(TX) / PA20(RX) → `/dev/ttyS1`

## 针号（从靠近两个 Type-C 的那一端开始为 1/2）

树莓派标准双排（左奇右偶，示意）：

```text
靠近 Type-C / UART 口 这一端
 1  3V3     2  5V      ← 雷达 VIN 可接 2 或 4（5V）
 3  ...     4  5V
 5  ...     6  GND     ← 雷达 GND（推荐）
 7  ...     8  UART_TX = PA27  → 接 LD2451 RX
 9  GND    10  UART_RX = PA20  → 接 LD2451 TX
11  ...    12  ...
... 一直到 39/40（靠近模组/天线一端）
```

## LD2451 实际怎么接

| LD2451 | 板子排针 | 信号 |
|--------|----------|------|
| **TX** | **脚 10** | 板 UART2 RX = PA20 |
| **RX** | **脚 8** | 板 UART2 TX = PA27 |
| **GND** | **脚 6** 或 9 | GND |
| **VIN** | **脚 2** 或 4 | **5V**（雷达要 5V；不够再外接升压） |

波特率：**115200 8N1**  
调试口：继续插丝印 **UART** 的 Type-C（不要改）

## 千万别接

板正面、靠近 CH 芯片旁的焊盘丝印 **TXD / RXD / DP / DM**：  
那是 **USB 转串口调试线（UART1）**，接雷达会和 NSH/烧录冲突。

## 如何确认脚 1

1. 排针靠近 **底边两个 Type-C** 的那一排尽头 = 1、2  
2. 背面焊盘：1 号常见为 **方焊盘**  
3. 数到第 8、10 脚（偶数那一列向下第 4、第 5 对）

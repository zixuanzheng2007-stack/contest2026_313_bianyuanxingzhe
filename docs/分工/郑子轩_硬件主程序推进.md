## 雷达接线（断电再改线）

开发板竖放、两个 Type-C 在下方，用**左边最底下**：`5V → 5V → GND → PA27 → PA20`

### 主雷达 2451（优先）

| 雷达 | 开发板 |
|------|--------|
| VIN | 5V |
| GND | GND |
| TX | PA20 |
| RX | PA27 |

灯不亮且 VIN 已是约 5V → 按损坏，改备用 2417。

### 备用 2417-D616（HKJG 板）

| 雷达 | 开发板 |
|------|--------|
| 白座最上 VCC | 5V（5V 不亮再改独立 12V 焊盘） |
| 白座第 2 GND | GND |
| 左上 TX | PA20 |
| 左上 RX | PA27 |

不要接 CANH/CANL、TXC/RXC、SWD。先只接电源看灯，再断电接 TX/RX。

Type-C 仍插丝印 **UART** 口看 NSH，不要把雷达接到板面 TXD/RXD。

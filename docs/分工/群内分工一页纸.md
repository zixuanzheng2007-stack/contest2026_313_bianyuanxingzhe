# 边缘行者 · 一页纸

> 全文：`边缘行者_任务规划与分工_白话版.md` · 截止 **9/20**

**产品：** 腰后看靠近，板子自己决定响不响；助手负责主动提醒，不代替测距。

**初赛两件事都要有：** ① 靠近能听见/看见提醒  ② 助手能对话，且靠近时不用人先问就会提醒

| 谁 | 干什么 | 交卷看什么 |
|----|--------|------------|
| **郑子轩** | 硬件、主程序、接线烧录、提醒出口、台架录像 | 能烧；靠近提醒短视频 |
| **王筠昊** | 数据处理、判断、应用编写、复现步骤 | 板上有距离和判断；会触发提醒 |
| **韦政宇** | 智能体上板、1 条技能、主动提醒 | 能问近况；靠近自己提醒 |

**验收节点：** 环境能编能烧 → 板上有数 → 靠近能感觉到 → 智能体会主动提醒 → 说明+视频能提交

板只在郑子轩处 · 先断电再改线 · 接口只认：距离/判断/提醒出口

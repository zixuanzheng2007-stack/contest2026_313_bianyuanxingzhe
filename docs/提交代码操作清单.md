## 4. AI Coding 日志（不会自动上传）

对话只在本机；要**主动导出**进仓再提交。

### 目录约定（仓内 `logs/README.md`）

```text

└── zixuanzheng2007-stack/     # 换成你的 GitHub 用户名
    ├── manifest.json
```

示例目录 `logs/your-github-login/` 是模板，**提交前删掉或换成真实目录**。

### 怎么导出

1. 打开官方手册（以手册为准）：  
   https://github.com/open-vela/docs/blob/dev-ai-contest-2026/zh-cn/contest_2026/ai_coding_log_guide.md  
2. 按手册用组委会提供的**日志归集工具**，从本机 staging 导出选定会话  
3. 把生成的 `manifest.json` + `.jsonl` 放进上面的目录结构  
4. 再 commit / push /（可同一 PR 或后续 PR）

> Cursor 本机对话在 agent-transcripts 等位置有记录，但**评委认的是手册规定的导出格式**；不要只丢原始 transcript 而不走官方工具。

### 提交日志示例


## 常见卡点

| 现象 | 处理 |

| `cla/signature` 失败 | 官网签署后 PR 评论 `/check-cla` |
| 日志目录用错名 | 必须用 GitHub 用户名 `zixuanzheng2007-stack` |

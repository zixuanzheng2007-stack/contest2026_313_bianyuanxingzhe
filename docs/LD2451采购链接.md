## 4. 配套小件（主控供电）

雷达要 **5V / ≥200mA**；若仅有锂电池 3.7～4.2V 则需升压；DevKit-LCD 若有稳定 5V 输出可直供。淘宝/京东搜索：

```
MT3608 升压模块 5V
```

或：

```
锂电池升压 5V 输出 300mA
```

任选带反馈可调、输出可锁定 5V 的小板即可。

## 6. 下单前 5 秒核对

1. 型号是 **LD2451**，不是 LD2450 / LD2410 / LD6002B  
2. 写明 **后方来车 / 车辆状态 / 测距测速**  
3. **不是** 联想打印机硒鼓「LD2451」  
4. 接口含 **UART**，供电 **5V**  
5. 优先官方店（上表链接）

建议先买 **1～2 只单模块** + 升压板，够阶段 1 感知闭环。

# 行人侧电自接近预警（腰带）

> openvela AI 硬件大赛项目说明 · v0.5 精简版  
> 定位：行人自带接近增强辅具（不替代 DOW / 骑行雷达 / 盲杖 / 导盲犬）

---

## 1. 做什么

静音电自从侧后靠近时，腰戴雷达主动震动/短耳标提醒。

| 用户 | 特化 |
|------|------|
| 普通人 / 银发 | 腰震为主 |
| 听障 | 强化震动，默认关语音；可选鸣笛等有声辅检 |
| 视障 | 与盲杖并用；短骨传导 + 腰震；不替代杖/犬 |

**验收**：直线辅路能提前告警；路口不疯震；断网仍可告警。

---

## 2. 怎么做

```
手机导航 ──BLE──► 路口等场景标签（只调档）
雷达 + IMU ──────► 本地算 TTC / 是否告警
                         │
                         ▼
                  ai_agent → Tool 执行震动/耳标
                         │
                  Skill：偏好 / 无障碍 / 简报
```

| 原则 | 说明 |
|------|------|
| 雷达主探 | 不靠听声发现电自 |
| 导航只调敏 | 不直接下令「震一下」；无导航 → IMU+默认档 |
| 判决在本地 | LLM 只做配置与简报 |
| Agent 必修 | 阈值越限 → Tool 执行（贴赛题） |

### 降敏（减路口误报）

- IMU：转弯 / 等灯 / 静止 → 降敏  
- 导航：距路口近、拥堵 → 降敏  
- 冲突时信 IMU（人可能没按导航走）

### 听障 / 视障

| | 听障 | 视障 |
|--|------|------|
| 主反馈 | 强震动（可左右编码） | 短耳标 + 腰震 |
| 语音 | 默认关 | 默认关/极简 |
| 探测 | 雷达为主；声为辅 | 雷达为主；默认可关相机 |

## 3. 硬件

| 角色 | 选型 |
|------|------|
| 主控 | **SF32LB52 LCD（DevKit-LCD）**；量产可再缩腰扣 |
| 必外挂 | 毫米波雷达 + IMU |
| 可选 | 骨传导（视障）、腕震从机（听障）、BK7258（听障声辅检） |

申领板须与腰带形态匹配；雷达整机体积可腰带化，续航按通勤间歇工作设计，勿对标 Varia 140 m。

---

## 4. 软件（openvela）

| 模块 | 作用 |
|------|------|
| radar / imu / nav_sync | 感知与导航偏置 |
| policy | TTC、扇区、降敏表 |
| ai_agent + Tools | `haptic_alert` / `earcon_alert` / `set_profile` / `set_nav_bias` |
| Skills | `approach-guard` · `nav-sync` · `a11y-hearing` · `a11y-vision` · `risk-brief` |

技术栈：openvela + C/C++ 安全环 + ai_agent；MiMo 仅语义。

---

## 5. 创新与边界

**创新**：行人侧雷达腰带；导航×IMU 调敏；听障/视障可切换反馈。  

**边界**：短距增强（约 15–40 m 目标），非车规；路口难零误报；不替代杖/犬/DOW。

---

## 6. 里程碑（4 周）

| 周 | 交付 |
|----|------|
| 1 | 雷达 → 震动 |
| 2 | TTC + IMU |
| 3 | 导航降敏 + hearing/vision 切换 Demo |
| 4 | 样机 + 断网告警 + Skill + 路测视频 |

---

## 7. 报名方向（可粘贴）

> 基于 openvela + ai_agent 的行人腰戴接近卫士：毫米波/IMU 本地判决侧后电自接近，导航 BLE 同步路口标签以调敏感度；Agent 阈值触发并 Tool 执行震动或短耳标。支持听障（触觉主通道）与视障（与盲杖并用）特化。不替代车端 DOW、骑行雷达、导盲犬或盲杖。

---

## 8. 合规要点

- 真机跑 ai_agent；≥1 Skill；接近 → Tool 执行  
- 断网可告警；唤醒词若用语音：你好，openvela  
- 板型与腰带故事匹配

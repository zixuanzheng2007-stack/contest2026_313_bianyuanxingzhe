## D. 失败对照

| 现象 | 处理 |
|------|------|
| 电源灯不亮 | 换数据线 / 换电脑口 / 确认插的是 UART 口 |
| 无新 COM | 换数据线；装 [WCH CH34x](http://www.wch.cn/downloads/CH341SER_EXE.html)；换口 |
| 有 COM 但无字符 | 波特率改 1000000↔115200；按复位；确认没被 Impeller/其他程序占用 |
| 一开串口就复位 | 关 DTR/RTS 流控 |
| 雷达无数据 | 先查 5V、TX/RX 交叉、共地、2451 单独 USB-TTL |

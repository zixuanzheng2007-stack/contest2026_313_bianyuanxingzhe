## 可直接粘贴到「请输入内容」的正文

**【项目名称与一句话定位】**  
项目名称：边缘行者——行人侧后电自/电动车接近预警腰戴系统。  
定位：面向城市步行通勤者及听障、视障出行人群，解决静音电自/电动车从侧后接近时难以及时察觉的问题；以腰带/腰包/帽圈等环状可穿戴形态，用毫米波雷达主动感知并用震动或短耳标提醒，作为辅具增强，不替代盲杖、导盲犬或车端开门预警。

**【目标开发板及选板理由】**  
首选：**SF32LB52 LCD（DevKit-LCD）**。  
理由：① 同族 SF32LB52，已适配 openvela（`sf32lb52_devkit_lcd`），软件与赛题栈可复用；② **可扩展 SDIO WiFi**，满足审核对联网拓展的要求，便于 ai_agent / MiMo 演示；③ 接口（SDIO/USB/TF/排针）更利于外挂 LD2451、IMU、震动；④ LCD 便于调试与告警档位显示；⑤ 竞赛原型取腰包主脑 + 外挂雷达，量产可再缩无屏腰扣。  
外挂自备：海凌科 HLK-LD2451（24G 后方来车检测模组，UART，预算远低于自购上限）。  
不选用表中已标「已发完」的 STM32H750B-DK，以及体积过大的待适配边缘 AI 板作为主控。原黄山派仅作低功耗形态参考。

**【核心功能清单（注明所需硬件能力）】**  
1. 侧后接近检测与 TTC 告警：毫米波输出距离/速度/方向 → 本地门限判决；需 **UART（接雷达）**、**GPIO/PWM（震动马达）**。  
2. 场景降敏（减路口误报）：IMU 识别转弯/静止 + 手机步行导航经 BLE 下发路口等标签只调灵敏度；需 **I2C/SPI（IMU）**、**蓝牙 BLE**、**Wi‑Fi（SDIO 扩展，用于 Agent/简报）**。  
3. 分级触觉/耳标反馈：通用腰震；听障强化震动编码；视障短骨传导耳标并与盲杖并用；需 **PWM/GPIO**、**音频输出（I2S/模拟，视障模式）**；LCD 可选显示告警档。  
4. openvela ai_agent「主动+执行」：接近越限主动触发，Tool 执行震动/记日志；Skill 含 approach-guard、nav-sync、a11y-hearing、a11y-vision、risk-brief；需能跑 **openvela + ai_agent**（DevKit-LCD 满足存储/算力与联网）。  
5. 断网可用安全环：无导航/无云时仍可本地告警；云端仅配置与简报，不判决是否告警。  
说明：不依赖板载摄像头作为主感知（雷达主路径）；听障可选后期加麦阵做鸣笛等有声辅检，非 MVP 必需。

**【端侧或云端技术方案】**  
- 端侧：openvela（大赛分支 `dev-ai-contest-2026`）+ DevKit-LCD 板级 BSP；C/C++ 实现雷达解析、跟踪/TTC、IMU×导航融合策略；告警经 **ai_agent Tool** 执行。  
- Agent：openvela **ai_agent** 框架；自定义 Skill（Markdown，`/data/agent/skills/`）；交互渠道 CLI/语音（唤醒词：你好，openvela）/ WebSocket 任一；开发期经 WiFi 连云。  
- 云端大模型：大赛发放的 **Xiaomi MiMo**（Token Plan），用于偏好对话、无障碍配置说明、风险简报文案；**不参与实时 TTC 判决**。  
- 手机侧：轻量 Companion/快应用，BLE 同步导航场景标签（距路口、拥堵等），不上传完整轨迹为默认。  
- 自备物料：LD2451 雷达、震动马达、可选骨传导模组、电池与腰包外壳（可用嘉立创打样券）。

# 边缘行者 · 三款毫米波雷达综合选型与接线手册

> 项目：边缘行者（行人腰戴侧后电自接近预警）  
> 主控：SF32LB52 LCD / DevKit-LCD（openvela）  
> 对比对象：  
> ① 海凌科 **HLK-LD2451**  
> ② 觅感 **MS60-1211S80M-BSD**  
> ③ 海凌科 **HLK-LD2417**  
> 版本：1.1 · 2026-08-05

---

## 0. 选型结论（先看这节）

| 角色 | 型号 | 建议 |
|------|------|------|
| **主选 / MVP 必买** | **HLK-LD2451** | 协议公开、5V/UART 好接、资料全、价约 ¥40、最贴「距离+速度+方向→TTC」 |
| **可选对照件** | **MS60-1211S80M-BSD** | 体积小、可直供 3.3～5V、功耗低；须确认协议 PDF；勿买「人存」SKU |
| **增强备选** | **HLK-LD2417** | 更广角、电自称测更远、体积更小；宽角易增路口误报；协议与 2451 不同，需另写解析 |

**不选**：LD2415H（180 m 路侧测速枪，9～24 V，主出速度、弱距离/TTC，不适腰戴）。

**接口定案（三款通用原则）**

- 与主控（DevKit-LCD）通信：**UART TTL 3.3 V**（不用 CAN、不用 RS485）  
- **禁止占用** Debug UART（勿用控制台口）  
- 雷达接 **UART2**（从 DevKit-LCD 排针映射引出；脚号以原理图为准）  
- 供电：雷达与主控 **共地**；LD2451/LD2417 建议独立 5 V；觅感可尝试 3.3 V 或 5 V（以手册为准）

## 2. 优劣分析（相对边缘行者）

### 2.1 海凌科 LD2451 —— 主选

**优势**

- 字段完整：距离 / 速度 / 方向 / 角度，直接支撑端侧 TTC  
- 5 V、UART、插针常见，接 DevKit-LCD 成本最低  
- 手册 + 串口协议 + APP 齐全，开源社区也有解析参考  
- 水平 ±15° 相对收敛，腰后安装时路口横向误报压力小于 ±60° 方案  
- 单价低，可买 2 只做备份  

**劣势**

- 模组偏大（70×35），腰带结构要专门固定  
- 均流约 100 mA@5 V，续航压力大于觅感  
- 电自极限距离不如 LD2417 手册宣称的 70 m（但你们只要 15～40 m）  

### 2.2 觅感 MS60-1211S80M-BSD —— 对照 / 轻量备选

**优势**

- **极小**（约 12×11 mm），最贴「帽圈 / 薄腰包」形态  
- **3.0～5.5 V**，有机会直接吃主控 3.3 V（仍建议先按手册测电流）  
- 功耗约 80 mA，续航更友好  
- 官方写明电自 / 自行车距离档，语义接近 BSD  

**劣势**

- 公开资料不如海凌科全，**协议/引脚必须向客服要 PDF** 才能写驱动  
- 电自称测约 **20 m**，偏短；夜间/遮挡下余量更紧  
- 贴片级尺寸：**几乎必然要焊接或转接板**，不适合纯杜邦线原型（见第 4 节）  
- 淘宝易买成「人存」SKU，必须核对 **BSD**  

### 2.3 海凌科 LD2417 —— 增强备选

**优势**

- 体积 40×25，比 2451 好塞  
- 电自称测约 70 m，汽车约 100 m；刷新约 65 ms  
- 宽角 ±60°，侧后覆盖更大  
- 有轨迹信息与分档检测系数，专业向更强  
- 宽压 5～12 V；GPIO 可做左右车道类硬信号（可选）  

**劣势**

- **±60° 对腰戴路口误报极不友好**，必须强依赖 IMU/导航降敏  
- 协议与 LD2451 **不通用**，固件要单独解析器  
- 引脚间距约 **1.5 mm**（官方介绍），杜邦线不好直接插，常需焊接或转接  
- 建议独立电源，>300 mA 能力；与 2451 相比集成略重  

### 2.4 三选一建议矩阵

| 你的优先级 | 选谁 |
|------------|------|
| 最快做出雷达→震动 Demo | **LD2451** |
| 最小体积 / 低功耗形态 | 主 **LD2451**，并行试 **觅感 BSD**（有协议再换） |
| 更远电自 / 更广侧后 | 评估 **LD2417**，但接受降敏工作量 |
| 预算紧、资料要稳 | **只买 LD2451 ×2** |

**推荐采购组合（竞赛）**

1. **必买**：LD2451 ×1～2 + 5 V 升压  
2. **可选**：觅感 BSD ×1（有协议 PDF 再下单）  
3. **第二迭代再买**：LD2417（阶段 1 跑通后再换）

## 3. DevKit-LCD 侧接口选择（三款共用）

### 3.1 选什么接口？

| 接口 | 是否采用 | 原因 |
|------|----------|------|
| **UART TTL 3.3 V** | **采用（主通道）** | 三款均可走串口；openvela 好驱动 |
| GPIO 告警脚 | 可选 | 2451/2417 有 GPIO；MVP 可只靠 UART 判决 |
| CAN | **不用** | 2417 预留未定义；本项目主控也非车载 CAN 主路径 |
| RS485 | **不用** | 非这三款主路径（LD2415H 才常带 485） |
| 蓝牙调参 | 仅开发期 | 用手机 APP 配参；量产以 UART 写参为准 |

### 3.2 DevKit-LCD 引脚分配定案

| 功能 | 引脚 / 资源 | 说明 |
|------|-------------|------|
| 控制台 Debug | **板级默认 Debug UART** | **禁止接雷达** |
| **雷达数据** | **UART2**（映射到排针闲置脚） | 推荐从扩展排针引出；**脚号到货后冻结** |
| WiFi | **SDIO WiFi 模组**（按到货版本） | 审核要求；与 UART2 脚不冲突 |
| IMU（若外挂） | I2C/SPI 空闲总线 | 降敏用 |
| 震动马达 | 空闲 PWM/GPIO | 若与 UART2 脚冲突则改脚 |
| LCD | 板载 LCD 接口 | 可选显示告警档；非安全环阻断项 |

**UART2 推荐映射原则**（以板级 `bsp_pinmux.c` / DevKit-LCD 原理图最终为准）：

- 选用排针上可作 UART 的脚，避开 SD/SPI、**SDIO WiFi** 与 Debug  
- SDK 示例常见：`USART2_RX/TX` 可映射到多组引脚  
- **阶段 0 冻结接线表**：记录「雷达 TX→MCU RX 脚号」并拍照；勿沿用黄山派 30P 脚表

### 3.3 逻辑接线（三款相同拓扑）

```
雷达 TX  ──────►  DevKit-LCD UART2 RX
雷达 RX  ◄──────  DevKit-LCD UART2 TX
雷达 GND ───────  DevKit-LCD GND（必须共地）
雷达 VCC ───────  见各型号供电小节（勿盲接 VBAT）
```

电平：雷达 UART 与 MCU 均为 **3.3 V TTL** → **无需电平转换芯片**。

## 4. 分型号接线方案与焊接说明

图例：

- **【免焊】**：杜邦线 / 排针直插即可  
- **【建议焊】**：建议焊排针或焊线，更稳  
- **【必须焊】**：不做转接板就无法可靠连接  
- **【另购】**：需要额外购买的物料  

---

### 4.1 方案 A · HLK-LD2451（推荐主方案）

#### 供电

| 项 | 做法 |
|----|------|
| 雷达 VCC | **5 V**（不能接锂电池 VBAT 3.7～4.2 V（须独立 5V）） |
| 【另购】 | **MT3608 或同类升压板**，输出锁定 5 V，能力 ≥300 mA |
| 升压输入 | 接板载 5V 或经升压自 VBAT/VSYS（注意极性） |
| 【建议】 | 升压输出串 **P-MOS / 开关**，GPIO 控制雷达电源，便于休眠 |
| 去耦 | 雷达 VCC 近端 【建议焊】10 µF + 0.1 µF |

#### 信号与接插件

| 连接 | 做法 | 焊接 |
|------|------|------|
| 模组侧 | 出厂常带 **2.54 mm 插针** | 若未焊针：【必须焊】插针或直焊线 |
| 到 DevKit-LCD | 杜邦线 → DevKit-LCD 排针 | 【免焊】（排针已在板） |
| 线序 | TX↔RX 交叉，GND 共地 | — |

#### 最小物料清单

| 物料 | 数量 | 备注 |
|------|------|------|
| LD2451 | 1～2 | 标题含「后方来车」 |
| 5 V 升压模块 | 1 | 【另购】 |
| 杜邦线母对母 | 若干 | 【另购】【免焊】 |
| 可选：排针/排母 | 1 套 | 模组无针时 【必须焊】 |

#### 调试系统（2451）

1. 手机 **HLKRadarTool**（蓝牙名 `LD2451_xxxx`）配距离/速度/方向  
2. PC 串口助手 115200，看原始帧 `F4 F3 F2 F1 … F8 F7 F6 F5`  
3. DevKit-LCD NSH / 自写 `radar` 任务解析协议 V1.03  

配置流程：使能 `0x00FF` → 写参 → 结束 `0x00FE` → 必要时重启。

推荐初值：最远 **40 m**、只检测靠近、最小速度 **5 km/h**、触发次数 **2**。

---

### 4.2 方案 B · 觅感 MS60-1211S80M-BSD

#### 供电

| 项 | 做法 |
|----|------|
| 电压 | **3.0～5.5 V** |
| 优先尝试 | 主控 **VCC_3V3**（测电流；不足再改 5 V） |
| 电流 | 约 80 mA，3.3 V LDO 需确认裕量 |
| 【另购】 | 若 3.3 V 不够稳：仍用 5 V 升压（与 2451 共用亦可） |

#### 信号与焊接（重点）

| 连接 | 做法 | 焊接 |
|------|------|------|
| 模组本体 | 约 **12×11 mm**，多为焊盘/邮票孔 | **【必须焊】** 或 **【另购】转接板/测试底板** |
| 推荐做法 | 买「带底板/带排针」的测试套件；或自制 2.54 转接小板 | 模组→转接板：**【必须焊】**；转接板→杜邦：**【免焊】** |
| 不推荐 | 直接飞线到腰带样机 | 机械强度差，易断 |

**下单前必问客服（复制发送）：**

1. 引脚定义图（VCC/GND/TX/RX/其它）  
2. UART 波特率与数据帧协议 PDF  
3. IO 电平是否为 3.3 V  
4. 是否有带排针的评估底板  

无协议 PDF → **不要下单写主驱动**。

#### 调试系统（觅感）

1. 厂商上位机 / 串口工具（以客服资料为准）  
2. 逻辑分析仪或 USB-TTL 抓包，对照协议写解析器  
3. 路测对比：同场景下与 LD2451 的距离/速度一致性

### 4.3 方案 C · HLK-LD2417

#### 供电

| 项 | 做法 |
|----|------|
| 电压 | **5～12 V**，能力 **>300 mA**；**<4.8 V 可能无法启动** |
| 推荐 | 独立 **5 V** 升压（与 2451 同方案即可） |
| 注意 | 官方建议独立供电，避免与屏/大负载共电轨跌落 |

#### 信号与焊接（重点）

| 连接 | 做法 | 焊接 |
|------|------|------|
| 封装 | 插针孔间距约 **1.5 mm** | 普通 2.54 杜邦 **插不上** |
| 推荐 A | 【另购】1.5 mm 间距排针 + 杜邦/端子线 | 排针进模组孔：**【建议焊】** |
| 推荐 B | 【另购】或自制 **1.5→2.54 转接板** | 模组侧 【必须焊】；2.54 侧 【免焊】 |
| GPIO | 可选接 MCU GPIO（左右/告警） | MVP 可不接 |
| CAN | 不接 | — |

#### 调试系统（2417）

1. 手机 **HLKRadarTool**  
2. PC **HLK-2417 Tool**（官网提供 exe）  
3. 串口 115200；协议见《HLK-LD2417 串口协议说明 V1.0.0》  
4. 可配：最远预警距离、最小预警速度、多段距离检测系数  

腰戴建议初值：最远预警 **30～40 m**（勿开到 100）；最小速度略提高；再靠 IMU 降敏压宽角误报。

| 震动马达 | 按板载焊盘或外接：【建议焊】 |

## 6. 调试系统对照

| 步骤 | LD2451 | 觅感 BSD | LD2417 |
|------|--------|----------|--------|
| 1. 上电电流 | ~100 mA@5V | ~80 mA | 看 5/12 V |
| 2. 手机 APP | HLKRadarTool | 厂商工具（确认） | HLKRadarTool |
| 3. PC 工具 | 串口助手 | 串口助手 | HLK-2417 Tool + 串口 |
| 4. 波特率 | 115200 | **问客服** | 115200 |
| 5. 看活数据 | 有靠近目标帧 | 按协议解析 | 轨迹/检测帧 |
| 6. 写参 | 距离/方向/速度/灵敏度 | 按手册 | 距离/速度/分段系数 |
| 7. 接 DevKit-LCD | UART2 收帧 | 同左 | 同左（换解析器） |
| 8. 台架验收 | 走廊接近→震动 | 对比 2451 | 宽角下看误报 |
| 9. 路测 | 辅路 + 路口降敏 | 短距够用性 | 重点测路口误报 |

**通用冒烟标准**

- [ ] 串口有稳定帧，TX/RX 未接反  
- [ ] 只靠近、远离不报（或策略过滤）  
- [ ] 断网仍可本地告警  
- [ ] 日志含距离、速度、角度、判决等级

| 1.5→2.54 转接 / 底板 | 1 | 必焊模组侧 | 随雷达询问客服 |
| HLK-LD2417 | 0～1 | **1.5 mm 必焊转接** | 海凌科店搜 `LD2417` |

## 8. 软件侧接口约定（便于换雷达）

固件建议抽象统一结构，换模组只换驱动：

```c
typedef struct {
  float range_m;
  float speed_kmh;      /* 或 m/s，团队统一 */
  float azimuth_deg;
  int   approaching;    /* 1 靠近 0 远离 */
  float snr;            /* 无则 -1 */
  uint32_t t_ms;
} radar_target_t;
```

| 驱动文件 | 对应 |
|----------|------|
| `radar_ld2451.c` | 主路径 |
| `radar_moresense_bsd.c` | 可选 |
| `radar_ld2417.c` | 可选 |

策略层 `policy_engine` **只消费** `radar_target_t`，不感知具体型号。

## 9. 最终选择声明（可写入组内决议）

1. **量产/参赛主雷达：HLK-LD2451**  
2. **通信接口：UART2（3.3 V TTL），共地；Debug UART1 不动**  
3. **供电：独立 5 V 升压（觅感可评估 3.3 V）**  
4. **焊接：2451 优先插针+杜邦；觅感与 2417 必须转接板焊接**  
5. **调试：官方 APP/上位机 → 串口抓帧 → openvela 解析 → 策略 → ai_agent Tool**  
6. **LD2417 / 觅感 BSD 仅作对照或第二迭代，不阻塞阶段 1**

## 2. 官方 PCB 网表：40P 排针 J0117（接雷达以这份为准）

文件：`docs/sifli_pinout_sources/SF32LB52-DevKit-LCD_PCB_V1.2.0.asc`

| 内容 | 行号 |
|------|------|
| 连接器定义 `J0117 = CON-2X20P-RSPBERRYPI-INTERFACE` | **L24706** |
| 封装类型 `CON-2X20P-RSPBERRYPI-INTERFACE` | **L24328** |
| 网络 `*SIGNAL* PA_27_UART_TXD` | **L28797** |
| 该网络接到 **J0117.8** | **L28798** |
| 网络 `*SIGNAL* PA_20_UART_RXD` | **L28879** |
| 该网络接到 **J0117.10** | **L28880** |
| 网络 `*SIGNAL* 5V`（含 J0117.2 / J0117.4） | **L29358–L29359** 等 |
| **J0117.2**（5V） | **L29368**（及多处 5V 岛） |
| **J0117.6**（GND） | **L26101** |
| **J0117.9**（GND） | **L26104** |
| NET 汇总 `NET PA_27_UART_TXD` | **L84130** |
| NET 汇总 `NET PA_20_UART_RXD` | **L84182** |

结论（排针物理脚）：

| 排针脚 | 网络名 | ASC 关键行 |
|--------|--------|-----------|
| **8** | PA_27_UART_TXD（板 TX） | L28797–L28798 |
| **10** | PA_20_UART_RXD（板 RX） | L28879–L28880 |
| **2 / 4** | 5V | L29358–L29368 |
| **6 / 9** | GND | L26101 / L26104 |

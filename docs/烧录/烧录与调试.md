# openvela 烧录与调试

> DevKit-LCD · COM7 · 固件 `nuttx.bin@0x12010000` · 共享盘 `VMware_share/artifacts/nuttx.bin`

---

## 1. 快速烧录（Windows）

1. Type-C 接 **USB to UART**（CH343），确认 COM 口（常用 **COM7**）
2. **关闭** PuTTY / 串口脚本，避免占口
3. 烧录时准备按 **RESET**

```powershell
cd e:\openvela\contest2026_313_bianyuanxingzhe

powershell -ExecutionPolicy Bypass -File scripts\host\flash_sf32.ps1 `
  -Port COM7 `
  -Firmware "VMware_share\artifacts\nuttx.bin@0x12010000"
```

或一键：`scripts\host\一键烧录并测屏.ps1`

失败可降波特率：

```powershell
& tools\sftool\sftool.exe -c SF32LB52 -p COM7 -b 115200 --compat true `
  write_flash --verify "VMware_share\artifacts\nuttx.bin@0x12010000"
```

**不要**随便整片 `erase_flash`（易伤校准区）。

---

## 2. 离开「测试界面」（lvgldemo）

屏一直停在 LVGL Demo，是因为旧固件开机脚本跑 **`lvgldemo`**，不是边缘行者主界面。

| 名称 | 含义 |
|------|------|
| **openvela** | 整包系统 → 产物 **`nuttx.bin`** |
| **主程序 `ew`** | 编进同一镜像的 NSH 应用 |
| **烧录** | 整份 `nuttx.bin` 写到 Flash `@0x12010000` |

**根治步骤：**

1. `board_overlay/.../rcS.user` 改为 `ew boot`（仓内已改）
2. Ubuntu 重编：`bash contest2026_313_bianyuanxingzhe/scripts/guest/build_ew_main.sh`
3. 用上面 sftool 烧 `VMware_share/artifacts/nuttx.bin`

**烧完确认**（串口 COM7 · 1000000）：

```text
ew help
ew boot
ew alert warn
```

| 现象 | 含义 |
|------|------|
| 上电深蓝待机 / `ew alert` 变色 | 主程序正常 |
| 仍是 LVGL Demo | 旧镜像或 rcS 仍有 `lvgldemo` → 重编再烧 |
| 黑屏但串口有 NSH | 屏排线/驱动，见 [`../硬件/DevKit-LCD.md`](../硬件/DevKit-LCD.md) |

临时绕过（已有 `ew` 时）：串口直接 `ew boot`；若 `lvgldemo` 占屏可能被盖住。

## 3. sftool vs Impeller

| 项目 | Impeller（官方 GUI） | sftool（命令行，推荐） |
|------|----------------------|------------------------|
| 固件格式 | 目录内需 `downfile.ini` | 单文件 `nuttx.bin@0x12010000` |
| 典型用途 | SiFli **Solution** 产线 IMG | **openvela** NuttX 镜像 |
| 接口 | UART / JLink | UART |

**竞赛 openvela 优先 sftool**；Impeller 仅在需要 GUI 时使用。

Impeller 烧 openvela 可选目录：

```text
VMware_share/artifacts/impeller_packet/
  downfile.ini
  nuttx.bin
```

Impeller 设置：UART · COM7 · 1000000 · 选 `impeller_packet` → **监控（单次）** → 烧录 → 按 RESET。烧录中勿占 COM7。

> 即使用 Impeller 烧 **nuttx.bin**，行为仍与 **lvgldemo / ew** 一致，不会恢复官方 Solution 触摸。

## 4. 测试脚本说明

| 工具/命令 | 测什么 | 不能代替什么 |
|-----------|--------|--------------|
| `sftool write_flash` | 烧 openvela nuttx.bin | Impeller Solution IMG |
| `lvgldemo` / `fb` | openvela 显示 | 官方出厂 UI / 触摸校准 |
| `i2c dev -b 1` | 触摸芯片是否在总线 | 万用表通断（不能测线序） |

- 显示、上电自启、串口 `ew` → 脚本结果可信
- 触摸 I2C 全 `--` → 硬件/接线问题
- `lvgldemo` 可交互；点不了是因无触摸输入

---

## 5. 建议验收顺序

1. sftool 或 Impeller 烧录成功
2. 上电 2s 内 UI 自启（当前为 `ew boot` 或 lvgldemo）
3. 串口：`ew alert warn` → 屏变色 + 日志
4. 触摸：`i2c dev -b 1` → 有设备地址才算硬件 OK

Windows 烧录后测屏：

```powershell
powershell -ExecutionPolicy Bypass -File scripts\flash_sf32.ps1 -Port COM7 -Firmware "VMware_share\artifacts\nuttx.bin@0x12010000"
powershell -ExecutionPolicy Bypass -File scripts\boot_check.ps1
```

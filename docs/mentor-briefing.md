# 行人腰戴接近预警系统 — 导师汇报提纲

> 面向导师介绍用 · 约 5～8 分钟口述版  
> 项目全称：基于 openvela 的行人侧电自/电动车接近预警（腰带形态）

---

## 一、一句话介绍

做一个**行人自己佩戴的腰带**，用毫米波雷达感知侧后靠近的静音电自/电动车，通过震动或短耳标提醒；支持与手机导航联动调节敏感度，并对听障、视障做反馈特化。系统跑在 **openvela + ai_agent** 上，面向 AI 硬件开发者大赛。

**不是**：自动驾驶、替代导盲犬/盲杖、车端开门预警（DOW）、自行车座杆雷达（Varia）的缩小版。

---

## 二、要解决什么问题

| 现状 | 缺口 |
|------|------|
| 电自静音，行人（尤其听障）难以及时察觉侧后超车 | 缺少「行人自带」的主动接近感知 |
| 车端 DOW、骑行雷达已有产品 | 服务对象是车主/骑手，**行人侧空白** |
| 视障辅具多管前方/读物 | **侧后快速目标**覆盖不足 |
| 纯听声方案 | 对静音电自几乎失效 |

核心场景：城市辅路/非机动车道直线通行时的侧后接近提醒；路口用策略降敏，避免误报导致关机。

---

## 三、创新点（建议作为汇报重点）

### 1. 用户与安装点创新（生态位）

把成熟的「后方接近雷达」思路，从**车/自行车**迁到**行人腰部自带设备**，补齐「车没装 DOW、人也不是骑手」时的防护空白。

### 2. 场景降敏机制（工程创新）

路口误报是可穿戴雷达的死穴。本项目用：

- **IMU**（转弯/等灯/静止）即时降敏  
- **手机步行导航 BLE 同步**（距路口、拥堵等标签）预降敏  
- 两者冲突时**信任 IMU**（人可能未按导航走）  

导航**只调灵敏度档位**，不参与「是否告警」的最终判决，保证断网仍可用。

### 3. 无障碍特化（产品创新）

同一套雷达感知，可切换配置：

| 模式 | 反馈 | 约束 |
|------|------|------|
| 通用 | 腰震为主 | — |
| 听障 | 强化震动编码，默认关语音 | 可选有声危险辅检（鸣笛等） |
| 视障 | 短骨传导耳标 + 腰震 | **与盲杖并用**，不替代杖/导盲犬 |

### 4. 系统架构创新（贴 AI 硬件方向）

- **本地**：雷达跟踪 + TTC/门限判决（低延迟、可离线）  
- **Agent**：阈值触发后通过 Tool **执行**震动/耳标；Skill 管理偏好、导航联动、无障碍配置、简报  
- 大模型只做说明与配置，**不算是否该震** → 避免「云端聊天当安全系统」

## 四、核心竞争力

| 维度 | 竞争力 | 说明 |
|------|--------|------|
| **差异化** | 较强 | 相对 DOW/Varia/助盲眼镜，用户与能力切面不同，可并存 |
| **刚需叙事** | 中强 | 静音电自混行是中国城市高频场景；听障/视障可加强社会价值叙事 |
| **可演示性** | 强 | 「来车→震动」「路口降敏」「听障/视障切换」三条 Demo 清晰 |
| **技术门槛** | 中 | 壁垒在腰部安装下的误报策略与无障碍反馈字典，不在雷达芯片本身 |
| **赛题匹配** | 中强 | 满足 openvela + ai_agent + 主动执行；需真机跑通 Agent/Skill |
| **商业成熟度** | 弱于巨头单品 | 尚无对标 Varia 的行人腰带爆款 → 既是机会也是验证风险 |

**一句话竞争力**：不是雷达功率更大，而是**正确的安装点 + 可穿戴降敏策略 + 无障碍反馈 + 端侧安全与 Agent 执行分离**。

## 五、技术可行性分析

### 5.1 总体判断

| 维度 | 结论 |
|------|------|
| 体积 | **可行** — 消费级毫米波模组可做成腰扣级；整机厚度主要受电池制约 |
| 功率/续航 | **有条件可行** — 须用接近检测类方案 + 通勤间歇工作，不能用人存在雷达充数，也不能按手环 μA 级幻想全天高占空比 |
| 探测精度 | **短距可行** — 目标预警距离约 **15–40 m**（给 2～5 s 反应）合理；不宜对标骑行雷达 140 m |
| 角度 | **粗分可行** — 后/左后/右后即可；精方位不是第一版目标 |
| 路口误报 | **难点** — 物理上会加重，必须靠 IMU×导航降敏；无法承诺零误报 |
| 量产成熟度 | **原型/参赛级可行，消费级仍待验证** |

### 5.2 关键参数对照（便于导师提问）

| 参考 | 距离/能力 | 形态 | 对本项目含义 |
|------|-----------|------|--------------|
| Garmin Varia 等 | 标称至约 140 m，24 GHz 量级 | 座杆、约烟盒厚 | 能力上限参考；腰带不追求同级距离 |
| 学术行人可穿戴原型 | 约数十米、数秒预警 | 可穿戴 | 证明短距行人方案物理上成立 |
| 智能家居「存在雷达」 | 数米、为人设计 | 极小、低功耗 | **不可直接当来车雷达用** |

### 5.3 技术路线（可行性落点）

1. **主传感**：24 GHz 级后向接近/多普勒（或等效 FMCW）模组，外挂于腰带  
2. **必选**：IMU 场景状态机  
3. **增强**：手机导航 BLE 场景标签调档  
4. **执行**：openvela 上 ai_agent Tool（震动/耳标）  
5. **KPI（第一版）**：直线辅路有效告警 + 路口误报可统计下降；不承诺全城全天候

### 5.4 主要风险与应对

| 风险 | 应对 |
|------|------|
| 路口乱震导致用户关机 | 导航预降敏 + IMU + 冷却时间；产品定位「辅路增强」 |
| 续航不足 | 通勤模式、静止降采样 |
| 衣物/金属扣遮挡 | 后向外露视窗、安装指引 |
| Agent 被做成贴牌 | 强制「越限 → Tool 执行」演示链路 |
| 过度安全承诺 | 汇报与说明书明确：辅助提醒，非功能安全认证产品 |

## 六、与大赛的关系（若导师关心）

- 方向：AI 硬件产品创新（openvela + ai_agent）  
- 合规要点：真机 Agent、自定义 Skill、阈值主动 + Tool 执行；断网可告警  
- 建议硬件：**SF32LB52 LCD（DevKit-LCD）** + 外挂毫米波（审核要求 WiFi 可拓展；见开发板更换分析）

## 八、30 秒电梯稿

> 我们做行人自己戴的接近预警腰带：用毫米波发现侧后静音电自，震动提醒；导航和 IMU 一起降低路口误报；听障偏触觉、视障偏短耳标并与盲杖并用。创新在行人生态位和可穿戴降敏，不在堆算力。技术上短距可做、腰带可集成，但续航和路口误报是主要工程挑战，第一版定位通勤增强而非车规安全。

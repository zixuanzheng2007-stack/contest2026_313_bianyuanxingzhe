# DevKit-LCD · 屏幕接线与自检

> 板：SF32LB52-DevKit-LCD V1.2.0 · 固件：`sf32lb52_devkit_lcd`  
> 来源：`docs/sifli_pinout_sources/SF32LB52-DevKit-LCD_wiki_zh.md`

---

## 1. 屏幕怎么接（不是排针，是 FPC）

DevKit-LCD 的屏走 **22pin FPC 座 J0102**（0.5mm 间距，下接触上翻），**不是** 40P 树莓派排针。

| 检查项 | 正确做法 |
|--------|----------|
| 连接器 | 主板 **22P FPC 座**（套件自带 LCD 模组） |
| 插入方向 | FPC **金手指朝下** 插入，锁扣/翻盖压紧 |
| 排针 | **40P 排针给雷达/UART2 用**，不接 LCD |
| 模组匹配 | 用套件原装 LCD；线序不对需转接板（见思澈转接指南） |

### FPC 关键信号（J0102，节选）

| 脚 | 信号 | 说明 |
|----|------|------|
| 1–2 | LEDK / LEDA | 背光（板子 PA01 PWM 驱动） |
| 12 | PA00 | LCD Reset |
| 3–10 | PA07–PA43 等 | QSPI / 8080 数据 |
| 13–16 | CLK/CS/DC 等 | QSPI 控制 |

触摸（可选）：I2C **PA30=SCL、PA33=SDA**（CTP），与 LCD 显示独立。

## 2. 接线好不好 — 三步判断

### A. 硬件（断电看）

1. FPC 是否 **插到底、锁扣压紧**（最常见问题：插一半 → 黑屏）
2. FPC 有无 **折痕、反插、金手指脏**
3. 上电后背光是否 **有一点点亮**（全黑且无背光 → 先查 FPC/背光）

### B. 软件节点（NSH）

烧 `sf32lb52_devkit_lcd` 后进 NSH：

```text
ls /dev
```

**接线/驱动正常时应看到：**

```text
fb0
lcd0
```

若没有 `fb0` / `lcd0`：固件不对或 LCD 驱动未起来（不是 FPC 松那么简单）。

### C. 功能测试（按顺序）

```text
lvgldemo          # 官方 LVGL 演示，应整屏有 UI
ew screen info    # 打印 fb0 分辨率
ew screen         # 红→绿→蓝→黑 各约 0.5s
ew alert warn     # 屏应变橙 + 串口打印 + 蜂鸣（若有 pwm0）
ew alert crit     # 屏应变红
ew alert none     # 屏变黑
```

| 现象 | 可能原因 |
|------|----------|
| 有 `fb0` 但全黑 | FPC 未插好 / 背光未开 / 屏模组坏 |
| `ew screen` 串口有输出但屏不变 | FPC 线序不对或屏与板不匹配 |
| `lvgldemo` 正常但 `ew` 不行 | 未烧含 edge_walker 的新固件 |
| 触摸无反应 | 见下文 **§6 触屏**；只影响触摸，**不影响**显示和 `ew` 填色 |

## 6. 触屏没反应（显示已亮）

触屏和显示走 **同一条 22P FPC**，但用的是 **后面几脚**（I2C + 中断）：

| FPC 脚 | 信号 | 作用 |
|--------|------|------|
| 18 | PA31 | 触摸中断 INT |
| 19 | PA33 | I2C SDA |
| 20 | PA30 | I2C SCL |
| 21 | PA09 | 触摸复位 RTN |

### 先确认用法

- 触屏 **只在跑 UI 程序时** 才有反应，例如先输入 **`lvgldemo`**，**不要退出**，再用手指点屏幕上的按钮。
- 若已回到 `nsh>` 黑屏命令行，点屏幕 **不会有任何效果**（正常）。
- 初赛 **接近提醒不依赖触屏**，屏显填色 + 蜂鸣即可。

### 硬件（最常见）

显示能亮、触摸不动 → 多半是 FPC **没插到底**，前面显示脚接触了、**18–21 脚没接触到**：

1. **断电**
2. 打开 FPC 锁扣，**拔出再插**，金手指朝下，用力插到底
3. 锁扣压紧，再上电
4. NSH 里再跑 **`lvgldemo`** 后试触

### 软件自检（会 NSH 时）

```text
lvgldemo              # 保持运行，别 Ctrl+C
# 另开串口或脚本发：
i2c bus
i2c dev -b 1 0x08 0x5d    # 扫触摸芯片常见 I2C 地址
ls /dev                   # 应有 input0
```

`input0 open success` 只说明驱动节点在，**仍要 FPC 接触良好 + lvgldemo 在前台** 才有手感。

### 仍不行

- 换官方套件 **原装 LCD 模组**（带触摸的那款）
- 触屏对本期 MVP **非阻塞**；可先继续雷达 + `ew` 联调

## 3. 与雷达接线别混

| 用途 | 接口 |
|------|------|
| **LCD 屏** | 22P FPC（J0102） |
| **LD2451 / LD2417 雷达** | 40P 排针 UART2：脚8 PA27、脚10 PA20、GND、5V |
| **NSH 调试** | Type-C UART（COM7），**不要**接雷达 TX/RX |

详见：`docs/DevKit-LCD_LD2451排针接线.md`

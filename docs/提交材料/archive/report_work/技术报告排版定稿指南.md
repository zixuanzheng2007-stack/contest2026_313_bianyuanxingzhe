## 2. Word 版式规范

### 2.1 页面

| 项 | 设置 |
|----|------|
| 纸张 | A4 |
| 页边距 | 上下 2.54 cm，左 3.17 cm，右 2.54 cm |
| 行距 | 正文 1.25 倍或固定 22 磅 |
| 字体 | 正文 **宋体 小四**；英文/数字 **Times New Roman** |
| 页眉 | 「边缘行者 · 技术报告」右对齐，宋体五号 |
| 页脚 | 居中页码「— 1 —」 |

### 2.2 封面（新增一页，pandoc 不含则手工插入）

```
边缘行者
—— 基于 openvela 的端侧毫米波接近预警与 AI Agent 原型

2026 openvela AI 硬件开发者大赛 · 提交作品技术报告

队伍：边缘行者（contest2026_313_bianyuanxingzhe）
成员：郑子轩、王筠昊、韦政宇
指导教师：修佳鹏
日期：2026 年 9 月
```

封面后插入 **分页符**，再开始「1、信息表」。

### 2.3 标题层级

| 层级 | Word 样式 | 示例 |
|------|-----------|------|
| 章 | 标题 1，黑体三号 | `# 3、正文` → **3 正文** |
| 节 | 标题 2，黑体四号 | `## 3.2 系统方案设计` |
| 小节 | 标题 3，黑体小四 | `### 3.2.1 系统总体架构` |
| 条目 | 标题 4，宋体加粗 | `#### 图形显示` |

**禁止**全文同一字号；目录用 Word「引用 → 目录」自动生成（更新域一次）。

### 2.4 表格

- 全表 **三线表**：顶线、表头下线、底线 1.5 磅；内线 0.5 磅或无
- 表头行 **加粗、浅灰底纹**（RGB 242,242,242）
- 表题在表上方：**表 3-1 LD2451 接线对照**（宋体五号居中）
- 验收表（§3.5）「状态」列：已验证 / 待测 用不同底纹区分

### 2.5 图片

- 图题在图下方，由 Pandoc 按正文出现顺序生成：**图 1、图 2……**（宋体五号居中）
- 宽度：**14 cm** 以内，保持比例；硬件照片优先横图
- 图与正文之间 **空一行**
- 报告内图序：图 1～图 12；正文引用必须与最终 PDF 一致

### 2.6 代码与架构

- NSH 命令、短代码：等宽 **Consolas 9 磅**，浅灰底纹文本框
- 长架构 ASCII：可改为 **Visio / draw.io 导出 PNG** 插入（比框线字符在 PDF 里更专业）
- 文件路径：`app/edge_walker/ew_ld2451.c` 用 Consolas，勿混在正文宋体里

### 2.7 摘要与关键词（可选加分）

摘要下增加：

**关键词**：openvela；LD2451；端侧预警；LVGL；AI Agent；Skill

## 3. §3.5 待测项定稿话术

录像/串口验收完成后，将表格「状态」列统一改为：

| 原「待测」项 | 定稿条件 | 建议写法 |
|--------------|----------|----------|
| WiFi ping | `ew wifi ping` 四层 OK | 已验证（2026-09-xx，LAN/ONLINE 见备注） |
| Agent 对话 | 录屏 B 段 + 气泡回复 | 已验证（Demo 视频 B 段） |
| 真机靠近 | 视频 A 段橙/红 | 已验证（分镜 clip_A） |
| 路测量化 | 可无 | 保留待测或写「竞赛阶段以定性演示为主」 |

# 屏上验收清单（烧录 nuttx_wifiui.bin 后）

固件：`VMware_share/artifacts/nuttx_wifiui.bin` @ `0x12010000`  
烧录：Guest `/dev/ttyACM0` 或 Windows **COM7**（1Mbps）

## 1. 预警

- [ ] 开机进预警页，雷达接好时不长期卡 NO RADAR
- [ ] NSH 或屏上触发：`ew fake 10 20` → 橙/红 + 蜂鸣
- [ ] 串口见 `[ew_agent]` + `[alert_output] level=...`（Agent Skill 链）

## 2. WiFi

- [ ] WiFi 页点 scan（列表数量记录：____ 个）
- [ ] **+ enter SSID manually** → 输入热点名 + 密码 → connect
- [ ] 状态行：`WIFI ON x.x.x.x` 或 `WIFI LAN` / 失败原因

## 3. Agent

- [ ] 点 Agent → 快捷句「Who are you?」或「告警怎么工作」
- [ ] 需联网时确认 WiFi 已连

## 4. Demo 录像（≤5min）

按 `Demo脚本与验收步骤.md` 分镜录屏，含：预警 fake、WiFi 手动 SSID、Agent 一句。

## USB 透传

VMware → 可移动设备 → **连接 CH343** → Guest 执行：

```bash
bash /mnt/hgfs/VMware_share/scripts/mailbox_exec_guest.sh
```

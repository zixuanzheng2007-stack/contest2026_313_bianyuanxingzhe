# LD2451 数据与策略复现（主机侧）

## 1. 编译运行 host_smoke

```bash
cd app/edge_walker
gcc -O2 -Wall -Wextra -o /tmp/host_smoke host_smoke.c ew_ld2451.c
/tmp/host_smoke
```

预期最后一行：`ALL PASS`

## 2. 门限（ew_decide）

- 使用 HLK 帧 `body[1]` 报警位：有靠近目标 → 至少 **SOFT**
- 距离 / TTC / SNR 可升级 **STRONG / EMERGENCY**
- 同批 UART 多帧时保留**最近有效靠近目标**，后续空帧不覆盖

## 3. 真机 NSH

```text
ew                    # 持续读 /dev/ttyS1 并打印 latch
ew fake 10 20         # 假目标 10m @20km/h
ew alert strong test  # 手动三档
```

## 4. 接线

雷达 TX→PA20，RX→PA27，5V/GND。详见 `docs/三款毫米波雷达综合选型与接线手册.md`。

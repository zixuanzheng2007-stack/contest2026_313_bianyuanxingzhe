# approach-guard

## 用途

当用户询问「告警太灵敏 / 太钝 / 各档是什么意思」时，用本 Skill 说明。  
**是否震动由端侧 `policy` 决定**；LLM / MiMo **不得**改写安全判决。

## 告警档位

| 档位 | 含义 | 典型条件（初值，可调） |
|------|------|------------------------|
| NONE | 无有效靠近威胁 | 过滤后无目标 |
| SOFT | 提前提醒 | 约 ≤25 m 或 TTC ≤5 s |
| STRONG | 明确预警 | 约 ≤15 m 或 TTC ≤3 s |
| EMERGENCY | 紧急 | 约 ≤8 m 或 TTC ≤1.5 s |

## 可调整偏好（配置，非实时判决）

- 最远关注距离：默认 40 m  
- 最小速度：默认 5 km/h（过滤慢目标）  
- 只检测靠近方向  

改偏好后应写入本地配置，由固件加载；对话仅解释与收集意图。

## Tool

- `haptic_alert`：按已判定的 `alert_level` **执行**震动 / 记日志，不重新计算 TTC。

## 主动触发

当端侧上报 `approach_threshold_exceeded` 时，Agent **主动**调用 Tool，无需用户先提问。

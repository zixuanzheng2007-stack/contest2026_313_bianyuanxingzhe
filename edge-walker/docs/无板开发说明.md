# 无板开发说明

## 目标

在 SF32LB52 LCD 与 LD2451 到货前，完成可单测的软件主路径：

```
假雷达帧 → protocol 解析 → policy(alert_level) → AgentBridge(主动+Tool)
```

## 运行

```bash
cd edge-walker
python -m pip install -e ".[dev]"
python -m pytest -q
python scripts/run_demo.py
python scripts/run_demo.py --hex
```

## 板上迁移映射

| 主机模块 | 板到后 |
|----------|--------|
| `simulator` / 假帧 | UART2 读 LD2451 真帧 |
| `protocol` | 迁 C/C++ `radar_ld2451`（字段语义保持） |
| `policy` | 迁端侧 `policy` 任务 |
| `agent_bridge` | openvela `ai_agent` Tool + Skill |
| `skills/approach-guard` | 拷到板上 `/data/agent/skills/`（路径以赛题为准） |

## 环境并行

- **本工程**：Windows 即可日常迭代  
- **openvela 编译 / goldfish**：另开 Ubuntu（可用 VMware）  
- **真机烧录**：板到后 USB-to-UART 连接

## 合规红线

- 判决只在 `policy`  
- Agent / LLM 只执行 Tool、解释配置  
- 断网安全环不依赖本工程的网络
